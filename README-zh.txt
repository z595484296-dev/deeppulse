深脉 DeepPulse 1.19.0 分享版
========================

一、系统要求

1. Python 3.9 或更高版本：https://www.python.org/downloads/
2. Windows 10/11 和 Edge、Chrome 等现代浏览器。
3. 行情与公告功能需要连接互联网。
4. 通达信 TQ-Local 是可选增强，只支持 Windows；未安装不影响深脉运行。
5. AKShare 是可选补充层；未安装不影响核心行情、公告与情绪分析。

二、Windows 一键启动

1. 先把整个 ZIP 解压到普通文件夹，不要直接在压缩包内运行。
2. 双击 start-deeppulse.bat。
3. 首次启动会打开一个服务窗口，随后浏览器自动进入深脉工作台。
4. 使用期间请保留服务窗口；关闭该窗口即可停止本次服务。

如果脚本没有自动打开浏览器，请查看 data\port.txt 中的端口，然后访问：
http://127.0.0.1:端口号/

三、命令行启动

在解压目录运行：

python server.py

默认访问地址为 http://127.0.0.1:8971。若该端口被占用，深脉会在 8971-8980
之间选择可用端口。

四、与 DeepSeek Harness 联动

深脉可以完全独立运行。需要接入 DeepSeek Harness 时，请阅读：
integrations\deepseek-harness\README.md

该适配器支持把当前页面、证券、行情、风险、官方公告、来源等级与通达信验证状态结构化发送给 Harness。
桌面 App 和 Harness 会自动在 8971-8980 中发现兼容的 1.19.0+ 深脉服务，不再固定依赖 8971。

总览顶部会自动生成“主动简报”：先核对数据日、更新时间、覆盖率与数据质量分，再把风险核验、
收盘复盘、自选和价格提醒整理成最多三件待办。你可以直接跳转处理、刷新、收起、标记已读或
恢复未读；已读只表示看过，不表示风险已经解除。点击“让 DeepSeek 深挖”后才会把白名单内
的事实、证据和研究任务交给 Harness 解释，模型不会替你自动保存或执行交易。

情绪引擎 2.0 同时展示温度、升降温方向、六维结构、结构背离、数据覆盖率与数据质量分。
“升阶/维持/降阶”当前是未校准的启发式状态倾向，不是收益概率；核心数据不足时会暂停仓位结论。
在情绪周期页点击“问问 DeepSeek”会完整传递公式、阈值、11 项信号、原始指标、历史快照、缺失项和通达信核验值；未选中个股时不会再把空公告列表误判为公告源缺失。
“昨日涨停今日表现”使用真实的“昨日涨停”板块成分和指数交易日校验；题材周期只使用深脉逐日积累的真实快照，不用休市日或重复数据补齐。
自选、提醒、日记、研究假设、助手记录和主动简报阅读状态保存在 data\profile.json，独立版、Harness和桌面App通过同一本机服务共享。
顶部铃铛是统一提醒中心：价格到达、情绪阶段变化和盘中异动都会在这里留痕。你可以选择平衡、只提醒重要事件或仅收入中心，设置安静时段，或者暂停到明早。每条提醒都会说明为什么触发；价格提醒默认及时送达，系统异动默认合并摘要，减少打扰。提醒和偏好同样在各运行端共享。
每条提醒还可以反馈“有用、已完成、少一点、不相关”。只有你的明确点击才会让深脉学习：“少一点”改为合并摘要，“不相关”改为只收入中心；可逐类恢复、恢复全部或清除学习记录。过期提醒不再打断，用户亲自设置的价格条件不会被学习规则自动降级。
总览新增“事件影响雷达”。该能力默认关闭，只有点击“授权开启”后才访问 AKShare 宏观日历与市场快讯，并在本机后台建立“事件→敏感行业→自选”路径。每条路径都会展示来源、时点、质量和透明规则，明确相关性不等于因果；可随时关闭，也不会连接交易账户或自动下单。事件状态同时供提醒中心、DeepSeek 和墨水屏“事件雷达”画面使用。
事件卡片可保存为 1/3/5/10/20 个工作日的“研究假设”。策略页会保留创建时事实、观察清单和预设反证，到期后由本机服务提醒你选择“支持/混合/不支持/事件失效”并写下依据；DeepSeek 只能辅助核验，不能改写原假设或替你确认结论。
策略页还可以为观察中的假设收集候选证据：首次冻结标的与上证指数基线，之后按可知时间补充巨潮资讯官方公告、标的累计变化、同期大盘变化和相对差值。事件服务已授权时后台最多每 15 分钟更新一次；未授权时只在你点击后收集。相对表现不是因果证明，系统不会据此自动修改结论或生成交易动作。
如需页面关闭后继续检查价格提醒，请进入“自选 → 价格提醒”，点击“开启后台监控”。该能力默认关闭，只在 A 股交易时段运行；界面会显示监控状态、等待提醒数和最近检查时间，可随时停止。它只在本机读取行情，不连接交易账户，不会自动下单；关闭本机深脉服务后监控也会停止。

总览“主动服务日程”可分别开启盘前准备、盘中检查和收盘复盘。三项默认关闭；开启后即使网页关闭，本机服务仍会在相应时段生成一次研究任务。任务会注明数据日；若数据未更新，深脉只提示检查数据源，不会把旧行情说成今天，也不会自动下单或替你保存复盘。
你也可以直接用一句话安排服务，例如“盘前提醒我准备，盘中只报重要变化，晚上22:30到8:00别打扰”。系统只会先生成透明草稿，必须点击“确认应用”才保存。服务时间线可显示未来安排，并支持只跳过下一次、暂停到明早或恢复；提到关注股票不会自动修改自选。
日程下方的“这些主动服务真的有帮助吗”只统计你明确选择的“有用、已完成、少一点、不相关”，分别显示盘前、盘中、盘后的帮助与完成情况。未反馈、打开页面和停留时间都不算负面。只有同一时段积累至少3次反馈且负向占优时才会出现调整建议；必须由你确认，并可随时撤销恢复。

数据源页提供“一键产品诊断”，会检查数据服务、Harness、桌面提醒、公开行情主备链路、通达信、AKShare 和墨水屏。界面会区分首次发现、持续存在与已经恢复；只读行情复核、只读通达信检测、AKShare 日历核对和已授权墨水屏网关重启可以由你点击执行，其余动作仍需人工确认。导出的诊断包不包含密钥、令牌、IP、路径或个人研究内容，并附带可直接提交到 GitHub 的问题模板。

开发或更新后必须运行 scripts\sync-all.ps1；它会同步独立版、Harness 内嵌工作台、桌面安装目录和桌面 App，并执行文件一致性校验。只检查不修改时使用 -VerifyOnly。

五、可选接入通达信 TQ-Local

1. 安装支持 TQ 的新版通达信，并启动 TdxW.exe、登录到主界面。
2. 打开深脉“数据源”页，点击“检测并接入”。
3. 页面会依次显示系统、安装、客户端进程和本地 HTTP 服务状态。

接入后，个股行情与 K 线优先使用本机通达信，市场专业统计用于情绪交叉验证；
不可用时自动回退东方财富和腾讯。深脉只开放读取接口，不读取账户、持仓，不能下单或撤单。
详细说明：integrations\tdx-tq-local\README.md

六、可选接入微雪 7.5 英寸墨水屏

进入“墨水屏”页，可以在没有硬件时预览真实的 800×480 黑白帧、切换提醒演示并下载
48,000 字节设备帧。收到微雪 7.5 英寸黑白裸屏和 e-Paper ESP32 Driver Board 后，
请阅读 hardware\README-zh.md，先用 dry-run 固件验证 Wi-Fi、设备令牌和帧校验，再根据
裸屏背面标签启用官方 epd7in5_V2 驱动。

局域网设备网关默认关闭，只开放只读 /device/v1/*，不要将 8988 端口映射到公网。
屏幕提醒是研究辅助，不是买卖指令，设备不会读取账户、持仓或执行交易。

七、数据与隐私

运行时数据保存在本目录 data 文件夹，包括配置、日志、情绪历史、题材快照、个人档案和端口信息。
本分享包不包含任何 API 密钥、个人自选或历史数据。
如果你以后再次转发，请不要把自己的 data\config.json 一并分享。

八、数据源

官方披露：巨潮资讯。
官方查验入口：上海证券交易所、深圳证券交易所、中国证监会。
市场行情与线索：东方财富；腾讯行情作为备援。
可选本地终端：通达信 TQ-Local（只读行情/K线/市场统计）。
可选补充数据：AKShare（交易日历；用户单独授权后用于宏观事件双源补充，不替代官方披露与行情主链路）。
