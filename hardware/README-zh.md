# 深脉 × 微雪 7.5 英寸墨水屏

本目录是深脉 1.5.0 的硬件端交付物，面向以下组合：

- 微雪 7.5 英寸黑白裸屏，800 × 480；
- 微雪 e-Paper ESP32 Driver Board（USB-C/旧版 Micro-USB 均可）；
- 电脑上的深脉服务与 ESP32 位于同一可信 Wi-Fi/LAN。

当前已完成微雪 7.5 英寸 V2 裸屏与 ESP32 Wi-Fi 驱动板实机联调。工作台提供 800 × 480 像素级预览、六种显示模式、三种刷新策略、设备配置、配对令牌、局域网取帧、帧长度/双哈希校验和 ESP32 网络固件；预览切换不会影响真屏，保存配置后设备才采用新模式。

六种显示模式：

- `focus`：个股专注，展示关注标的、K 线、情绪温度与指数；
- `overview`：市场总览，展示指数脉冲和整体情绪；
- `emotion`：情绪周期，展示温度、阶段、六维结构和市场核心指标；
- `watch`：自选组合，同屏展示最多 6 只自选股；
- `hotspot`：热点雷达，展示领涨行业与涨跌停、炸板率等结构数据；
- `alert`：提醒优先，目标条件触发时切换为大字号提醒。

## 已知硬件口径

微雪官方资料给出的 7.5 英寸 V2 黑白屏为 800 × 480，单色完整帧正好是 `800 × 480 ÷ 8 = 48,000` 字节。ESP32 驱动板内部固定连线为 MOSI/P14、SCLK/P13、CS/P15、DC/P27、RST/P26、BUSY/P25；使用裸屏座时无需再用杜邦线连接这些信号。

驱动板的屏幕配置拨码需根据官方表设置。7.5 英寸屏通常列在 B 档，但最终必须以收到的驱动板版本、屏背标签和当期官方表为准，断电后再调整拨码。

官方资料：

- https://www.waveshare.com/wiki/E-Paper_ESP32_Driver_Board
- https://www.waveshare.com/wiki/7.5inch_e-Paper_HAT_Manual

## 电脑端与真屏验证

1. 启动深脉，进入“墨水屏”。
2. 选择关注股票和显示模式，先检查“所选模式”预览，再按需查看“提醒演示”。
3. 下载 `.bin`，文件必须是 48,000 字节。
4. 保持设备网关关闭时，所有硬件接口只允许本机工作台访问。
5. 开启网关，把页面显示的局域网地址与设备令牌填入 ESP32 配网页面；保存模式后等待设备下一次轮询刷新。

网关只公开只读的 `/device/v1/*`，不会公开自选、日记、DeepSeek 密钥、账户或交易接口。令牌在可信局域网内通过 HTTP 发送；不要暴露到公网，也不要做路由器端口转发。怀疑泄露时在页面旋转令牌并重新配对。

## ESP32 固件

Arduino 工程位于 `esp32/DeepPulse_EPaper/`。

### 第一阶段：无屏编译与网络验证

默认 `hardware_config.h` 中 `DEEPPULSE_WAVESHARE_7IN5_V2=0`，固件以 dry-run 运行：会完成配网、鉴权、取帧、48,000 字节与 SHA-256 校验，但不会驱动屏幕。

1. 安装 Arduino IDE 与 Espressif ESP32 开发板支持。
2. 复制 `hardware_config.example.h` 为 `hardware_config.h`。
3. 打开 `DeepPulse_EPaper.ino`，开发板选择与微雪官方示例一致的 ESP32 板型。
4. 上传后打开 115200 波特率串口。
5. 首次启动会建立 `DeepPulse-Setup` 热点，密码为 `deeppulse-setup`。
6. 手机连接热点后访问 `http://192.168.4.1/`，填 Wi-Fi、深脉网关地址（例如 `http://192.168.1.20:8988`）和设备令牌。
7. 串口出现 `frame verified: 48000 bytes` 即说明软件链路已闭环。

在串口发送一行 `RESET` 可清除配网数据并重新进入配网模式。

### 第二阶段：V2 真屏与智能刷新

1. 拍清裸屏背面完整标签、排线型号、驱动板正反面与拨码位置。
2. 从微雪官方资源安装最新版 `esp32-waveshare-epd` 库，并先运行官方 `epd7in5_V2-demo` 的全刷、快刷与局刷测试。
3. 确认是支持局刷的新 V2，而不是 `V2_old`；2023 年前后不同批次不可仅凭分辨率猜测。
4. 将 `hardware_config.v2-smart.example.h` 复制为 `hardware_config.h`，重新编译并通过 USB 上传固件。
5. 串口启动信息应为 `DeepPulse E-Paper 1.1`；页面“设备固件”显示“智能刷新就绪”后，新策略才真正作用于实屏。

固件升级不会清除 Preferences 中的 Wi-Fi、网关地址和设备令牌；但首次启用局刷时仍应观察若干轮是否存在错位或明显残影。出现异常可在页面选择“稳定全刷”，无需重新配网。

## 刷新策略

- ESP32 每 15–300 秒检查一次新帧；
- 普通画面按 60–1800 秒的显示间隔刷新；
- 目标价提醒首次出现可立即刷新，持续提醒不会每次轮询重复刷屏；
- 收到帧必须同时满足 HTTP 200、48,000 字节和整帧 SHA-256 一致；
- `stable` 稳定全刷：每次到期更新都全刷，残影最少；
- `smart` 智能混合：决策内容没有变化时跳过刷新；小范围变化局刷；模式、提醒或大范围结构变化采用全刷/快刷；
- `fast` 快速全屏：优先使用快刷，并按页面设定的次数定期执行全刷；
- 时钟与交易状态位于可忽略区域，不会单独触发实屏刷新；
- 智能策略最多连续轻刷若干次，随后自动全刷；24 小时内也会至少执行一次维护性全刷；
- 局刷窗口从 `x=0` 开始并按 8 像素对齐，以降低部分 7.5 V2 批次的窗口兼容风险；任何初始化或内存失败都自动回退全刷。

墨水屏保留最后一帧是正常特性。断电不等于清屏；长期收纳前可用官方程序刷白并休眠。

## 边界

屏幕上的 `ALERT` 是用户设定目标价的研究提醒，不是自动买卖指令。深脉硬件端不读取账户、不持有仓位、不下单；行情、情绪和提醒都可能延迟或错误，必须回到正式行情与公告源复核。
