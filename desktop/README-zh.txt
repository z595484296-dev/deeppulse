深脉 DeepPulse · DeepSeek Harness 桌面 App
==========================================

1. 双击 DeepSeekHarnessDesktop.exe。
2. App 会先连接本机 3080 端口；若端口未启动，会在相邻/上级目录查找 DeepSeek Harness，或读取 DSH_DESKTOP_HOME 后自动启动。
3. App 从 8971~8980 中发现兼容的深脉服务，并优先使用同目录 DeepPulse 文件夹中的后端。
4. 转发给其他电脑前，请确认对方已安装 Python 3.9+ 和 DeepSeek Harness；也可以让对方先独立启动 Harness 的 3080 端口。
5. 使用通达信 TQ-Local 时，请先启动并登录官方通达信金融终端。
6. 深脉只调用行情、K线和市场统计等只读接口，不包含委托、撤单或账户操作。
7. 总览“事件影响雷达”默认关闭；明确开启后才会读取 AKShare 宏观日历和市场快讯，并把可核验路径同步给提醒中心、DeepSeek 与墨水屏。
8. 可把事件保存为研究假设；创建时事实和反证不会被后来行情自动改写，到期后由你在策略页确认复盘结论。
9. 研究假设可收集官方公告、标的相对大盘表现等候选证据；这些记录不会自动形成因果结论或交易动作。
10. 总览个人研究驾驶舱会汇总明确关注项与研究任务；优先级可解释、可调整，调整不会改写原始记录。
11. 策略页研究记忆只使用你确认的复盘，并可关闭相似结构提醒、补充方法改进或隐藏单条记忆；不会根据收益自动修改策略。

版本：1.39.0
本版新增可追溯研究结果卡与墨水屏“研究结果”模式：证据、缺口、陈旧项和同源警告分别展示，复盘结论仍由用户填写与保存；AKShare 只作为保留最终上游和时点的研究增强层。系统级子进程生命周期保护继续生效，桌面外壳意外退出后不会遗留旧的深脉或 Harness 服务。
完整同步：独立版、Harness 内嵌工作台、桌面 App 使用同一份前端和兼容后端版本。
安全分享：维护者使用 scripts/package-desktop.ps1 打包，自动排除 data、日志、端口文件和本机配置。

仅供研究与学习参考，不构成投资建议。
