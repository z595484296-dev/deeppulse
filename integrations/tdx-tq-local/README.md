# 通达信 TQ-Local 集成

深脉 1.3 起支持把通达信 TQ-Local 作为**可选本地只读数据源**。它不是深脉的硬依赖：
通达信未安装、客户端未启动或本地服务不可用时，深脉自动使用东方财富与腾讯备援链。

## 接入顺序

深脉按以下顺序检查，不会跳步：

1. 当前系统必须是 Windows。
2. 在 Windows 卸载注册表中确认已安装支持 TQ 的新版通达信。
3. 确认 `TdxW.exe` 已启动并登录到主界面。
4. 向固定回环地址 `http://127.0.0.1:17709/` 发送只读探测请求。

打开深脉的“数据源”页，点击“检测并接入”即可查看每一步的真实状态。

## 提供的能力

- 个股实时行情：通达信可用时优先，失败后回退东方财富、腾讯。
- 日/周/月 K 线：通达信可用时优先，失败后回退公开行情链。
- 情绪交叉验证：读取 `SC03/SC04/SC23/SC24/SC30/SC31/SC33/SC35/SC39`
  等市场专业统计，并随 `/api/emotion` 和 Harness 上下文提供来源状态。
- 连接状态：`GET /api/tdx/status?probe=1&fresh=1`。

## 安全边界

`tdx_local.py` 使用固定的方法白名单，只允许行情、证券信息、交易日历和市场统计查询。
账户、资产、持仓、委托、下单、撤单等接口没有加入白名单，即使本地服务支持也无法由深脉调用。

所有请求只发送到本机 `127.0.0.1:17709`。深脉不读取交易账号，不保存券商凭据，
也不会生成或运行 `tqcenter.py` 策略文件。

如需完全关闭本地增强，可在启动前设置：

```powershell
$env:DEEPPULSE_TDX_ENABLED='0'
python server.py
```
